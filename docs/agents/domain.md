# Domain documentation

This is a single-context repository.

Before changing established vocabulary or consequential product/technical decisions, read root `GLOSSARY.md` and relevant records under `docs/adr/` if they exist. Their absence is acceptable: create them lazily through domain modelling only when a resolved term or decision needs a durable home.

Use existing project vocabulary consistently. Surface conflicts with an existing decision instead of silently overriding it. Current historical decisions remain in `decisions.md`; do not migrate them solely for format consistency.
