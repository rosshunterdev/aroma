# 13: Recommend hosting and maintenance ownership

**What to build:** An evidence-backed recommendation for low-maintenance hosting, domain ownership, deployment, recovery and ongoing update responsibilities while retaining static HTML/CSS/minimal JavaScript as the planning default.

**Blocked by:** None (can start immediately).

**Owner:** Ben/Codex

**Status:** ready-for-agent

- [ ] Options compare cost, ownership, deployment, rollback/recovery, handover and expected update frequency.
- [ ] Developer-managed, client-editable and hybrid maintenance models are evaluated without assuming a CMS is required.
- [ ] Any proposed architecture or CMS change is presented for explicit approval rather than introduced incidentally.
- [ ] The recommendation is complete before production hosting is selected or the final site is released.
