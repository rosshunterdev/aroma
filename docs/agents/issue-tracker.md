# Issue tracker: local Markdown

Specs and implementation tickets live under `.scratch/<feature-slug>/` and are committed when they represent active project work.

- Specification: `.scratch/<feature-slug>/spec.md`
- Tickets: `.scratch/<feature-slug>/issues/<NN>-<slug>.md`
- Each ticket records `Status:` near the top and appends discussion under `## Comments`.
- `to-spec`, `to-tickets` and implementation workflows read and write these files.

Keep one independently verifiable outcome per ticket.
